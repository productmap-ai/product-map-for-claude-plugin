# Product Map for Claude Code

Product Map's product-management agents as slash commands in Claude Code. `/pm:product-strategy-roadmap`,
`/pm:prd-specification`, `/pm:user-research-planner` and the others answer with your project's knowledge base as
context, inside your normal coding session.

## Install

```
/plugin marketplace add productmap-ai/product-map-for-claude-plugin
/plugin install pm@productmap
/mcp
```

`/mcp` shows the `productmap` server; pick it and sign in with your Product Map account in the browser.

Full documentation: [claude-plugin/README.md](claude-plugin/README.md). Website: https://www.productmap.io.
Support: hey@productmap.io.

This repository is published from the Product Map monorepo; changes land here on each plugin release.
